# 🎵 SoundWave 2.0

**SoundWave 2.0** is a simple music-listening web application built using **Node.js, Express.js, and EJS**. The project provides a welcoming homepage for users and allows them to navigate to the songs section.

## 📌 Project Description

SoundWave is a music platform designed to provide users with a simple and enjoyable way to explore and listen to music.

The homepage displays the application name dynamically using **EJS templating** and provides a link to the songs section.

> 🎶 *"We help you listen to what you love, serving soulful music since 1998."*

## 🛠️ Technologies Used

* **HTML** – For creating the webpage structure
* **Node.js** – JavaScript runtime environment
* **Express.js** – Web application framework
* **EJS** – Template engine for dynamic HTML rendering

## ✨ Features

* 🎵 Welcome page for SoundWave
* 🔄 Dynamic application name using EJS
* 🌐 Express.js server
* 🎧 Navigation to the songs section
* ⚡ Simple and lightweight web application

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone <your-github-repository-link>
```

### 2. Open the project folder

```bash
cd SoundWave
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node index.js
```

### 5. Open in browser

Visit:

```text
http://localhost:5000
```
